COIL FINDER - primeira versão

Arquivos:
- index.html: aplicativo
- coils.json: 337 bobinas extraídas da listagem fornecida
- manifest.webmanifest + sw.js: instalação como PWA
- exemplo-etiqueta.jpg: exemplo enviado pelo usuário

Para funcionar com câmera no celular, hospede esta pasta em HTTPS (por exemplo GitHub Pages). O OCR usa Tesseract.js via CDN na primeira abertura; a consulta dos 337 registros é local.
